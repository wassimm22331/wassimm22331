## Featured Projects

### [League of Legends Esports Win Predictor](https://github.com/kayzo001/league-of-legends-e-sports-game-predictor)

Collaborative end-to-end machine learning project predicting the outcome of professional League of Legends matches from the game state at 15 minutes using **Oracle's Elixir** esports data.

- Exploratory data analysis and preprocessing
- Feature engineering from gold, XP, objectives, KDA and champion draft information
- Logistic Regression, Random Forest, Gradient Boosting, AdaBoost and XGBoost
- Hyperparameter tuning and cross-validation
- Soft Voting and Stacking ensembles
- Leakage-aware preprocessing
- Approximately **77–78% test accuracy**
- Flask web application for interactive predictions

My contribution included work on **exploratory data analysis, preprocessing and the machine-learning pipeline**.

### [DDoS Attack Detection for IIoT Networks](https://github.com/wassimm22331/DDoS-Attack-Detection-Using-Machine-Learning)

Machine learning project focused on detecting malicious network activity in an Industrial IoT environment.

- Dataset of approximately **988,000 network records**
- PCAP / JSON data processing
- Network-behavior feature engineering
- Decision Tree, KNN and Random Forest comparison
- Features based on request frequency, duplicate behavior and MQTT topic activity
- Best Decision Tree result: approximately **97.7% accuracy**
- F1 score of approximately **0.89**
